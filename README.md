# Team Science Workshop

Slides and materials for a workshop on why teamwork matters in academia and beyond, for the Danish Advanced Research Academy (DARA) PhD Fellow Induction 2026.

**Live slides: https://travisjwiltshire.github.io/teamscienceworkshop/**

## Contents

- `dara-teamwork-workshop.qmd`: Quarto (reveal.js) source of the slides
- `index.html`: rendered slides, served via GitHub Pages
- `handouts/`: activity handouts
- `img/`, `files/`, `dara.scss`, `_extensions/`: supporting assets and styling

To rebuild the slides, run `quarto render dara-teamwork-workshop.qmd`.
